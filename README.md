# Измерение показателя адиабаты воздуха по температурной зависимости частоты резонатора Гельмгольца

Авторы: Рудачихин П.А., Свиногонов М.А. (Б04-507, МФТИ, 2026)

## Суть работы
Определение γ = Cp/Cv по температурной зависимости частоты резонатора Гельмгольца (стеклянная банка с трубками).

## Методика
1. Определение концевой поправки δ методом добавочных шеек (график f⁻²(L))
2. Измерение f²(T) → вычисление γ

## Результат
**γ = 1.38 ± 0.08** (табличное: 1.40)

- `analisys` — построение графиков
- `description` — отчёт
